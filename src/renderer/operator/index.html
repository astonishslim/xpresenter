          Panorâmico: uma imagem larga dividida entre as telas, na ordem 1, 2, 3… Sem sobreposição serve para
        painéis de LED lado a lado. Com sobreposição (projetores cruzando a imagem), as bordas ganham edge blending
        para a emenda não aparecer: ajuste a porcentagem até a faixa sobreposta ficar com o mesmo brilho do resto.
